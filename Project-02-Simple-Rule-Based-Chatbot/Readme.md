AI Chatbot

A console-based C++ chatbot developed during my 12th-standard holidays, before beginning my engineering journey.

About the Project

This project is a simple rule-based chatbot designed to simulate an interactive AI assistant through a C++ console application.

The chatbot is presented as "ChatGPT" and allows the user to interact with different predefined categories such as academics, problem solving, solutions, and entertainment.

The project was developed as a learning exercise to explore object-oriented programming, user interaction, menu-driven programs, conditional logic, loops, and basic input handling in C++.

«Note: This is a rule-based simulation created for learning purposes. It does not connect to ChatGPT, an AI model, or an external API.»

Features

- Takes the user's name
- Provides a chatbot-style introduction
- Offers multiple assistance categories
- Provides predefined responses based on user selection
- Includes a simple mood-based interaction
- Allows the user to return to the main menu
- Validates the menu navigation input
- Provides an option to exit the application

Available Options

The chatbot provides four main categories:

1. School Ace
   Provides a predefined academic-oriented interaction.

   2. Problems
      Simulates assistance with solving a problem and encourages the user to explore alternative approaches.

      3. Solution Seeker
         Provides a predefined response for users looking for solutions or cross-checking their work.

         4. Entertainment
            Provides a mood-based interaction involving jokes and a predefined story.

            The program also allows the user to enter "0" to exit.

            Program Structure

            The application is implemented using a "Gpt" class.

            The class contains functionality for:

            - Greeting the user
            - Displaying the available assistance categories
            - Processing the user's menu selection
            - Providing predefined responses
            - Handling mood-based interaction
            - Returning to the main menu
            - Exiting the application

            A separate "backToMenu()" function is used to handle menu navigation and validate whether the user wants to continue.

            How It Works

            1. The program creates an object of the "Gpt" class.
            2. The chatbot asks for the user's name.
            3. It displays a welcome message and available assistance categories.
            4. The user selects an option.
            5. The program provides a predefined response based on the selection.
            6. For the entertainment option, the program additionally takes the user's mood.
            7. The chatbot asks whether the user wants to return to the main menu.
            8. The interaction continues until the user chooses to exit.
