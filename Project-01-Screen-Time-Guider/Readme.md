Screen Time Guider

A console-based C++ application developed during my 12th-standard holidays, before beginning my engineering journey.

About the Project

Screen Time Guider is an interactive, rule-based console application designed to provide screen-time guidance based on the user's age and daily screen usage.

The application is presented as a chatbot named YuAI. It collects the user's name, age, and daily screen time, and provides predefined guidance and recommendations based on the entered information.

The project was developed as a learning exercise to explore C++ programming, object-oriented programming, user interaction, and decision-making logic.

«Note: YuAI uses pre-coded, rule-based responses. It does not use machine learning or an external AI model.»

Features

- Collects the user's name, age, and daily screen time
- Performs basic input validation
- Provides age-based guidance
- Classifies screen-time usage into different levels
- Generates predefined recommendations
- Provides an interactive console-based experience

How It Works

1. The program introduces the Screen Time Guider.
2. It displays instructions to the user.
3. YuAI introduces itself.
4. The user enters their name.
5. The user enters their age.
6. The user enters their daily screen time.
7. The program provides guidance based on the user's age.
8. The program classifies the user's screen-time usage.
9. Final recommendations are displayed.

Project Structure

The application is organized using a "ScreenTime" class with separate member functions for different stages of the interaction, including introduction, user input, guidance, screen-time classification, and final recommendations.
