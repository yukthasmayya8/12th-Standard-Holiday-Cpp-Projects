#12th Standard Holiday C++ Projects

A collection of C++ projects I developed during my 12th-standard holidays, before beginning my engineering journey.

These projects were created as part of my early exploration of programming and software development. They reflect my initial attempts at building interactive, user-oriented applications using C++.

Projects

1. Screen Time Guider

An interactive, rule-based console application that provides screen-time guidance based on the user's age and daily screen usage.

Concepts explored:

- Object-Oriented Programming
- Classes and Objects
- Encapsulation
- Conditional Statements
- Loops
- Switch-case
- User Input and Validation
- String Handling

2. Simple Rule-Based Chatbot

A console-based, rule-based chatbot designed to simulate an AI assistant. It provides predefined interactions for academics, problem solving, solutions, and entertainment.

Concepts explored:

- Object-Oriented Programming
- Classes and Objects
- Encapsulation
- Member Functions
- Menu-Driven Programming
- Conditional Statements
- Loops
- Functions
- String Handling
- Input Validation

Technology

- Language: C++
- Development Stage: 12th-standard holidays
- Purpose: Learning and experimentation

About This Collection

These projects represent an early stage of my programming journey, created before I started my engineering studies.

Rather than being polished production applications, they are preserved as a record of the concepts I explored and the ideas I experimented with at that stage.
