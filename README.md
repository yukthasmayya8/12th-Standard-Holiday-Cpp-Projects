# 12th Standard Holiday C++ Projects

A collection of beginner-friendly C++ console applications developed during my 12th-standard holidays, before beginning my engineering studies.

These projects represent my early exploration of software development, object-oriented programming, user interaction, input validation, and rule-based application design.

## Projects

### 1. Screen Time Guider

A rule-based console application that provides screen-time recommendations based on a user's age and daily device usage.

#### Concepts Demonstrated

- Object-oriented programming
- Classes and objects
- Encapsulation
- Member functions
- Conditional statements
- Loops
- Switch statements
- User input and validation
- Basic mathematical operations
- String handling
- Console-based interaction

### 2. Simple Rule-Based Chatbot

A menu-driven console chatbot that provides predefined interactions related to academics, problem-solving, solutions, and entertainment.

This project demonstrates how structured rules and conditional logic can be used to create a simple conversational experience without artificial intelligence or external APIs.

#### Concepts Demonstrated

- Object-oriented programming
- Classes and objects
- Encapsulation
- Member functions
- Menu-driven programming
- Conditional statements
- Loops
- Functions
- String handling
- Input validation
- Rule-based response handling

## Prerequisites

To compile and run these projects locally, install a C++ compiler.

### Windows

Install one of the following:

- MinGW-w64
- MSYS2
- Visual Studio with C++ development tools

### macOS

Install Xcode Command Line Tools:

```bash
xcode-select --install
```

### Linux

Install the GNU C++ compiler:

```bash
sudo apt update
sudo apt install g++
```

Verify that the compiler is installed:

```bash
g++ --version
```

## Run the Projects Locally

### 1. Clone the repository

```bash
git clone https://github.com/yukthasmayya8/12th-Standard-Holiday-Cpp-Projects.git
cd 12th-Standard-Holiday-Cpp-Projects
```

### 2. Run the Screen Time Guider

Navigate to the project directory:

```bash
cd Project-01-Screen-Time-Guider
```

Compile the program:

```bash
g++ main.cpp -o screen-time-guider
```

Run the program on macOS or Linux:

```bash
./screen-time-guider
```

Run the program on Windows:

```bash
screen-time-guider.exe
```

### 3. Run the Simple Rule-Based Chatbot

Return to the repository root and navigate to the chatbot project:

```bash
cd ..
cd Project-02-Simple-Rule-Based-Chatbot
```

Compile the program:

```bash
g++ main.cpp -o rule-based-chatbot
```

Run the program on macOS or Linux:

```bash
./rule-based-chatbot
```

Run the program on Windows:

```bash
rule-based-chatbot.exe
```

## Compile Using C++11 or Later

If your compiler requires an explicit C++ standard, use:

```bash
g++ -std=c++11 main.cpp -o application-name
```

For example:

```bash
g++ -std=c++11 main.cpp -o screen-time-guider
```
